## 4. 实现要点（账实同源）

- 退避策略只存于 `签名规`：`退避秒=30 / 退避倍数=1 / 退避上限秒=300`，
  间隔公式 `min(退避秒 * 退避倍数 ** (失败次数-1), 退避上限秒)`；
  页面、投递、重试、对账全部经 `app/services/退避闸.py:读规()` 取同一口径。
- 原子争用：进程内按事件号取同一把 `threading.Lock`，库内
  `BEGIN IMMEDIATE` 后在同一事务里「重读窗状态 → 写正式尝试 →
  写审计账册」，同成败；HTTP 拦截返回 `429 + Retry-After`。
- 审计表 `退避账册` 钉 `窗指纹 WB-<sha256[:18]>`，闸口值：
  `放行落账 / 窗内拦截 / 人工开窗`。
- 影子↔正式同票：每笔正式尝试对应一条 `闸口='放行落账'` 账册，
  按 `尝试号` 一一核对；历史/种子数据由 `_补票同票()` 补齐。
- 对账口径：正式表内同窗紧挨的后续失败判 `窗内连打/非法落账`；
  审计表的 `窗内拦截` 计入拦截数；`窗内连打数 = 非法落账 + 审计拦截`。
- 静态资源双树已同步且 `diff -rq` 无差异：
  `backend/app/static/` ↔ `/workspace/static/`。
